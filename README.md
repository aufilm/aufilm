# Aufilm

Production planning software for film, inside ChatGPT, Claude and Gemini.

Paste a screenplay in the conversation. Aufilm returns the production package: breakdown, shooting schedule, Day Out of Days and a complete, editable budget. Professional exports rebuild inside Saturation via their official API and open in Movie Magic Scheduling via FDX.

- Website: https://aufilm.app
- Connector docs: https://aufilm.app/connector-docs
- MCP Registry: app.aufilm/aufilm

Free for the first production (breakdown, schedule, DOOD, editable budget, no account). Production US$79 per production.

By Auf Wassen.

This repository holds the public MCP manifest (server.json) and brand information. The application itself is hosted software; there is no application code here.
